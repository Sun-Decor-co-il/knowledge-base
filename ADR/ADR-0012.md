## Context

Необходимо определить структуру базы знаний.

## Decision

В корне репозитория размещается README.md.
Он выполняет роль навигатора по базе знаний.

## Consequences

- GitHub автоматически отображает главную страницу.
- Obsidian использует тот же документ как стартовую заметку.
- Исключается дублирование информации.
