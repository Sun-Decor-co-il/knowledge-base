## Context

Необходимо определить ответственность каждого репозитория организации.

## Decision

Каждый репозиторий имеет единственную ответственность.

Пример:

- .github — стандарты GitHub;
- knowledge-base — инженерные знания;
- landing-page — продукт;
- GitHub Project — управление разработкой.

## Consequences

Уменьшается связность.
Повышается масштабируемость организации.
