## Context

Необходимо определить момент создания GitHub Issue.

## Decision

Идея сама по себе не считается задачей.
До появления исполнимой работы Issue не создаётся.

## Consequences

Уменьшается количество “мёртвых” Issue.
Backlog содержит только реальные задачи.
