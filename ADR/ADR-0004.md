## Context

Необходимо определить ответственность GitHub Project и репозиториев.

## Decision

GitHub Project используется исключительно для управления работой.
Репозитории используются исключительно для хранения результатов работы.

## Consequences

Project отвечает на вопрос: `Что мы делаем?`

Repository отвечает на вопрос: `Что мы уже сделали?`
