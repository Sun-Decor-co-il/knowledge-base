## Context

Необходимо определить место хранения общих стандартов GitHub для всех репозиториев организации.

## Decision

Репозиторий .github используется для хранения организационных стандартов GitHub:

- Issue Templates;
- Pull Request Templates;
- CONTRIBUTING;
- CODE_OF_CONDUCT;
- SECURITY;
- профиля организации и других общих файлов.

Документация продуктов и инженерная база знаний в этом репозитории не размещаются.

## Consequences

- все репозитории используют единые шаблоны;
- стандарты централизованы;
- изменение стандартов выполняется в одном месте.
