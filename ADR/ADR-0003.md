## Context

Необходимо определить модель управления задачами нескольких продуктов.

## Decision

Организация использует один GitHub Project верхнего уровня.
В него подключаются все репозитории организации.
Проект является единой системой управления разработкой.

## Consequences

- единый Backlog;
- единый Workflow;
- единая аналитика;
- единые представления (Views).
