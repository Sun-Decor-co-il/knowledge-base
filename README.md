# Sun Decor Engineering Knowledge Base

## Назначение

Единая инженерная база знаний организации Sun Decor.

В этом репозитории хранятся архитектурные решения, стандарты разработки, инженерные процессы и документация, не относящаяся к конкретному продукту.
